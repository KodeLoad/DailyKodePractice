Given a string str[], replace all spaces in it with "%20". The string has sufficient space at the end to hold additional characters.

Examples:
```
Input: str = "Mr John Smith   "
Output: "Mr%20John%20Smith"
```

```
Input: str = "Hello World    "
Output: "Hello%20World"
```

Expected Time Complexity: O(n)
Expected Auxiliary Space: O(1)

Constraints:
1 ≤ |str| ≤ 10^5
