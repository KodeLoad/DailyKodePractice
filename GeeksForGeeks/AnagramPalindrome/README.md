Given a string s, the task is to check whether it can form a palindrome by rearranging its characters (i.e., it is an anagram of some palindrome).

Examples:
```
Input: s = "aabbcc"
Output: true
Explanation: "aabbcc" can be rearranged to "abccba", which is a palindrome.
```

```
Input: s = "aabbccc"
Output: true
Explanation: "aabbccc" can be rearranged to "abcccba", which is a palindrome.
```

```
Input: s = "abc"
Output: false
Explanation: All three characters have odd frequency; cannot form a palindrome.
```

Expected Time Complexity: O(n)
Expected Auxiliary Space: O(1)

Constraints:
1 ≤ |s| ≤ 10^5
